# 公众号素材整理

把微信公众号文章正文里的图片批量下载下来，并整理成 Word 文档和 PowerPoint 演示文稿。

## 使用

### 方式一：直接运行 exe（无需 Python 环境）
直接在项目根目录下双击运行：
- **可执行文件**：[`公众号素材整理.exe`](公众号素材整理.exe)（单个独立文件，即开即用）

### 方式二：Python 源码运行
```bash
pip install -r requirements.txt
python weixin-gui.py
```

也可以双击 `run-gui.bat`（优先使用项目内 `.venv`，没有则用系统 `pythonw`）。

### 重新打包
双击根目录下的 [`build-exe.bat`](build-exe.bat)，打包完成后会自动生成在根目录 `公众号素材整理.exe`。

### 操作步骤
1. 粘贴文章链接（“粘贴”按钮会从分享文案里自动提取链接）。
2. 文件名可留空，默认使用文章标题。
3. 选择保存位置和导出格式，点击“开始生成”（或按回车；`Esc` 取消）。

每次导出会在保存位置下新建 `<文件名>_<时间戳>` 子文件夹，里面是按顺序编号的图片和 `.docx` / `.pptx`。保存位置与格式选择会记在 `%APPDATA%\微信公众号素材整理\config.json`。

## 处理规则

- 只提取正文 `#js_content` 中的图片，不含头像、二维码等；“图片消息”类文章从页面脚本中提取。
- 跳过 1×1 等占位图；webp 等 Office 不支持的格式自动转为 PNG。
- Word 为 A4 竖版，小图不放大，长图按页面高度缩小；PPT 每页一张图，居中适配。
- 微信要求人机验证或文章已删除时会给出提示。

`weixin-word-ppt.py` 是早期命令行原型，仅作参考。
